# 湖泊蓝视觉规范 · 已确认版本

## 整体感觉

清爽、柔软，像与熟悉的学习搭子聊天。对话是主内容，任务和资料辅助当前行动。延续圆润气泡、悬浮控件、轻量卡片。Muse 是早期参考，正式开发以本包的已确认稿为准。

## 排版

- 中文字体：PingFang SC、Microsoft YaHei 和系统 sans-serif。
- 桌面对话正文 16px、窄屏 15px；卡片标题 19px、窄屏 18px；辅助信息通常 13px；按钮 14px。
- 正文行高约 1.8，标题约 1.5，一般标题 500–550 字重；按钮统一 500。
- 正式业务正文遵守仓库字号下限，不把说明文字的小字号扩展成大段正文。
- 长消息自然换行，不复制样例的硬换行来固定宽度。

## 布局与滚动

- 常规桌面左栏 304px，内部宽 260px，左右约 22px；顶部 91px 起放“今天三件”，不恢复旧版 146px 偏移。
- ≤1240px 左栏约 278px，内部宽 242px。≤850px 隐藏左栏。
- 对话宽 min(1040px, 主区域宽 − 96px)，中桌面按参考使用 66px 边距。1387px 宽窗口的对话约 987px，1600px 宽窗口为 1040px，不回到固定 676px。
- 输入区最大宽 1080px；对话和输入围绕同一中轴。
- 页面适配视口高度，不设 1000px 整页最小高度；flex 对话区域 min-height:0 并承担滚动，输入与提示保持可见。
- IP 容器常规桌面 102px、大桌面 112px，矮窗口约 83px、窄屏约 78px；保持图片比例。
- 资料入口为右上轻浮层；展开工作台尚未逐项确认。

## 气泡

用户右侧、浅湖蓝；小满左侧、浅灰。宽度随内容而变，桌面最大约对话区 76%，窄屏约 92%。圆角约 20px，靠说话方向的下角约 6px。连续回复间距较小，换说话人时留出更多间距。引用入口小而清楚，真实出处由业务数据提供。

## 任务与资料

三张任务都有完整卡片。任务卡圆角 18px，浅白／浅灰微渐变、细边框；当前项用 #EEF7FA → #DEEDF3 浅蓝渐变。左侧书本、纸笔、复习页图标，右侧状态圆点；SVG 已在 screen.html。

任务卡常规高度至少 110px，矮桌面约 100px；完成态依然清晰可读。

“我的资料”为紧凑分组：浅白底、13px 外圆角、24px 文件图标底座。标题与列表间距 8px，演示展示行高 38px。静态资料行不可点击；正式增加交互时，点击目标遵守仓库至少 44×44px 要求，不将展示行高直接视为触控目标标准。

## 卡片

练习卡常规宽 470px、大桌面 490px，窄屏自适应。圆角 22px，1px #DAE7ED 边框，内边距约 18px 21px。

背景仅有很淡的白色 → #FAFCFE → #F1F7FA 渐变，右上少量透明 #E7F2F7 光感。阴影轻，避免厚重外发光。

## 按钮：最后确认的统一规范

| 属性 | 共用值 |
|---|---|
| 高度 | 44px |
| 左／右内边距 | 各 14px |
| 圆角 | 14px |
| 字号／字重 | 14px / 500 |
| 行高 | 20px |
| 边框宽 | 1px |
| 宽度 | 文字＋相同内边距；min-width:0 |
| 按钮间距 | 桌面 10px、窄屏 8px |

- “晚点再做”“开始练习”都是四字，当前字体下均约 86×44px。86px 是样例结果，不是所有按钮的固定宽度。
- 开始练习无箭头，不保留箭头空位；不单独设置 124／136／165px 最小宽度。
- 主次仅通过填充、边框、文字色区分，不能使用不同 padding、字号、字重或高度。
- 主按钮渐变 #3A7B91 → #306B80，白字、细内高光、轻阴影；次按钮浅白底、#DCE5EB 边框、#607581 文字。
- 主按钮渐变两端与白字对比度约 4.75:1、5.93:1，实际实现仍需检查所有状态。
- 新业务按钮若需图标，定义明确的图标按钮变体，不偷偷给一侧多加空位。

## 输入和全局控件

输入框白底、25px 圆角、轻边框和阴影；发送按钮 44×44px、16px 圆角、同主按钮微渐变。@某讲为浅蓝标签，AI 提示位于输入框下方，不能遮挡内容。

其他图标以细线为主；任务图标带轻微层次。动效克制，尊重 prefers-reduced-motion。
