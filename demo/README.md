# 小满学习搭子 · 可点击 demo

一个以对话为主的学习 personal agent 原型：你只管上课和交资料，小满记得你学到哪，每天告诉你该学的三件事，让你看得见自己在进步。

这是**纯前端的演示页**，单个 HTML 文件，所有数据和 AI 回复都是预设的（页面里标了“模拟”的地方就是还没接真实能力的部分）。

## 怎么打开

下载或 clone 后，用浏览器直接打开 `index.html`。不需要安装任何东西。

顶部黄色条会提示当前第几步、下一步点哪里。随时可以点“重新开始”。

## 演示什么（8 步，两天）

1. **定目标**：说“备考 PMP，12 月 14 日考试”，小满出目标拆解卡，点“好”后左栏出现今天三件事。
2. **交资料**：交第 6 讲课件，小满按页读完、整理成学习文档。
3. **提问**：问“关键路径怎么算？”，回答标出【第 N 页】，点开看原文。
4. **做题**：5 道题在一张卡里原地切换，做题时前面带答案的对话先收起来。
5. **补一补**：复习上一讲术语，第一天收工。
6. **跳到明天**（演示用）：也可以选“跳过两天”“跳过 8 天”看中断后回来怎么处理。
7. **第二天**：小满先开口；左栏可以换强度（轻松 / 正常 / 冲刺）。
8. **做完三件**：重做错题、交第 7 讲、练第 5 讲，看板上掌握度上升。

## 体现的产品规则

- 每天最多三件，分别来自“学新的 / 练一练 / 补一补”。
- 小满改计划都先出建议卡，点了才生效，可以撤销；一次只让用户做一个决定。
- 中断后回来不堆积、不追责；看板只写“这周学了 N 天”，不做连续打卡。
- 重做答错不卡住，那道题过几天换个问法再出；任务做了就算完成。
