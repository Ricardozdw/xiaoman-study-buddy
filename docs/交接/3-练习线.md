# 交接 · 3 练习线

> 先读 [分工方案](../分工方案.md)：产品规则、技术约定、协作方式对所有人都适用。

## 你负责什么

小满按一讲出题、用户做题、错题记下来以后换个问法再考，并据此算出每个知识点的掌握度。对应 PRD 的 **F4 做题**，演示的第 4 步和第 8 步的做题部分。从界面、接口到提示词都由你完成。

范围：
- “出题”这个 AI 能力：一讲全文 + 题数 + 难度 → 单选题（题干、选项、答案、解析、页码、易 / 中 / 难）；出完让模型只看题干和原文再答一遍，答案对不上的题丢掉。
- “错题换问法”这个 AI 能力：原题 + 对应页原文 → 同一知识点的新题。
- 题目卡：一组题一张卡，原地换题，答完看解析，点“下一题”才换；做完收成一行总结，可展开回看；卡上有“这道题有问题”。
- 做题时，前面带答案的对话先收起，右侧原文面板自动关闭，小满只留头像。
- 判分、作答记录、错题本；答错的题自动进之后的“补一补”，过几天换个问法再出；重做时答错不卡住。
- 每个知识点的掌握度（0–100），以及下次该复习的日子。

## 要做出什么

- 出 5 道题在 30 秒内；每讲抽 20 道评测，答案正确、能在原文里找到依据。
- 对话里每组题只占一张卡；做题时看不到前面的答案。
- 5 道错 2 道，错题本里能看到这 2 道；第二天重做后，掌握度变化看得见。
- 点“这道题有问题”后，这道题进 bad case 库。
- 题目生成一次就存起来复用。

## 和别人对接

- **资料线**：用它的“取资料内容”函数拿全文。
- **计划线**：提供“练一练”和“补一补”需要的东西，包括哪些讲能出题、哪些错题和知识点该复习；做完一组题，告诉计划线这件任务完成了。格式事先商量好。
- **看板与上线线**：提供每讲掌握度、本周做题数、待重做错题；出题自检对不上、“这道题有问题”都进 bad case 库；调用 token 要记录；出题评测集交给他们。
- **问答线**：用户在对话里说“出几道题”，会转到你这里。
- **A**：题目卡的样式和答错时的说法按 A 的规范来（答错说“常错，没关系”）。

## 必须遵守

- 任务做了就算完成，对错只影响掌握度。
- 不显示红色失败标记，不责备。
- 两周内只做单选题，不做简答题和模拟考试。
