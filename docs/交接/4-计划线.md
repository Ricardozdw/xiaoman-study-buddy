# 交接 · 4 计划线

> 先读 [分工方案](../分工方案.md)：产品规则、技术约定、协作方式对所有人都适用。
> 负责人邮箱和代码目录见 [地基给各线](../地基给各线.md)（2026-11-04 A 确认）。

## 你负责什么

产品的核心：小满从大目标拆出每天三件事，带着用户一件件做，第二天先开口接上昨天，中断几天回来也有台阶下。对应 PRD 的 **F1 目标拆解、F5 今天三件事与强度、F6 中断后回来**，以及 F7 里小满开场和建议的部分。演示的第 1、5、6、7 步。这条线工作量最大，别的线先做完的人会来帮你。

范围：
- 目标拆解：在对话里问目标和考试日期、课程几讲、学到第几讲、每天多少时间 → 目标拆解卡（分阶段、每天三件的来源、默认强度），点“好”才生效，可撤销，“说说怎么改”能用一句话重排。
- 今天三件事：每天最多三件，各从“学新的 / 练一练 / 补一补”取一件，某处没有就由另外两处顶上。用规则算，不用 AI。放在左栏，可以直接点开始，做完自动勾上，小满引导下一件。
- 强度三档：轻松约 15 / 正常约 30（默认）/ 冲刺约 50 分钟，件数不变、分量变。左栏直接切；用户说“今天只有 15 分钟”，小满出建议卡。
- 中断后回来：没做的不堆积；落后不多只出一张卡；落后较多出重排卡，给 2–3 种补法；超过 7 天先问目标还算不算数。
- 建议卡、重排卡、收工卡，以及所有建议的“点了才生效、可撤销”。
- “小满开场与建议”这个 AI 能力：根据昨天的记录、今天的安排、中断天数 → 开场白和建议卡文案，只能从固定的几种动作里选。
- 演示开关：“跳到明天 / 跳过两天 / 跳过 8 天”，界面上标“演示用”。

## 要做出什么

- 确认拆解卡后，左栏立刻出现今天三件；撤销后左栏清空。
- 任何操作都不会让某天超过三件；切强度后左栏立刻更新。
- 三件做完有收工反馈，并告诉用户明天的三件。
- 点“跳到明天”后，小满先开口，第一件是昨天的错题。
- 跳过两天 / 8 天后，每次只让用户做一个决定；所有改动点了才生效、可撤销；选“先休息一阵”后不再排任务。
- 开场和建议里没有“你断了几天”这类说法，也没有责备的话。

## 和别人对接

- **资料线**：拿到“这一讲资料交完了”，用来勾掉“学新的”。
- **练习线**：拿到“哪些讲能出题、哪些错题该复习”，用来排“练一练”和“补一补”；拿到“这组题做完了”，用来勾任务。
- **问答线**：用户说“调安排”类的话，会转到你这里。
- **看板与上线线**：提供“这周学了几天”和目标进度；开场 / 建议出错进 bad case 库；调用 token 要记录。
- **A**：小满开场、建议、收工、中断回来的文案和表情按 A 给的来。

## 必须遵守

- 每天最多三件；改计划必须先出建议卡；一次只让用户做一个决定。
- 不连续打卡，不追责。
- 默认值不算用户的选择：用户跳过的问题要写明“先按……安排”。
