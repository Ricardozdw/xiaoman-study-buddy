# 小满学习搭子 · 两周分工方案 v2（AI 上手版）

Nov 4, 2026 · @路明泽

**一句话：你只管上课和交资料，小满记得你学到哪，每天告诉你该学的三件事，让你看得见自己在进步。**

这份 v2 取代 [旧分工文档](https://claude.ai/artifact/5wuYkKqTCmyiB54cq24UiE)。比旧版多了两件事：**bad case 库与数据飞轮**、**成本记录**（共约多 2 个人日，两周节奏不变）。

**11-04 更新：后端改用开源项目 [Personal-Agent](https://github.com/hubooooooo/Personal-Agent) 当底座，不再用 Dify。** 它是 MIT 许可的 FastAPI + LangGraph 个人助理底座，自带模型主备切换、调用记账、👍 / 👎 反馈、版本化提示词、回归测试、确认卡、登录和行级权限。学习相关的功能仍由我们自己做，MVP 功能不变，前端仍用 React。E、F 从“Dify 拖拽”改为“用 Claude Code / Codex 改提示词文件 + 跑评测”。

**怎么用**：先看下面两张总表找到自己；再翻到自己那一节，读完要点，把“复制给你的 AI”整块复制，贴给你的 Claude Code / Codex / Claude 对话，它就能上手。

## 两周节奏：4 段 3 道关

10 个工作日分 4 段，每道关当天下午现场演示，过了才往下走，没过当场定砍什么。

1. **第 1–2 天 · 定义**：把底座跑起来；接口、卡片、数据表（含 bad case 表）定稿。第 2 天关：接口和卡片定稿，定下 bad case 规矩。
2. **第 3–5 天 · 跑通“第一天”**：定目标 → 交资料 → 提问 → 做题。**第 5 天关：一份 PDF 走到做完题**（看 demo 第 1–4 步）。这是最关键的一关；不通就先砍图片和扫描件，学习文档只留要点和知识点。
3. **第 6–8 天 · 跑通“第二天”**：补一补、跳到明天、小满先开口、换强度、看板。**第 8 天关：第二天能接上昨天**（看 demo 全部 8 步）。
4. **第 9–10 天 · 打磨与演示**：修体验问题、彩排、录屏备份，第 10 天正式演示。

两周后演示两段，可以先点一遍 [可点击 demo](https://claude.ai/artifact/QNQPNJgPJin1rsqk4HqLvM)：

- **第一天**：说出目标（备考 PMP，12 月 14 日）→ 小满拆成每天三件 → 交一讲课件、看学习文档 → 问一个问题，回答带出处 → 做 5 道题错 2 道 → 复习上一讲术语，收工。
- **第二天**：一打开小满先开口，今天三件是重做昨天的错题、学第 7 讲、练第 5 讲；时间紧可换“轻松”。三件做完，看板上掌握度上升。

参考文档：[MVP PRD](https://claude.ai/artifact/NvuYb5wf2gi39FR7Mujmk7)（功能和验收）· [技术实现主文档](https://claude.ai/artifact/FwzuAyM7n8Foi1xbG9BuDd)（接口和数据表）· demo 源码在 GitHub 私有仓库 `Ricardozdw/xiaoman-study-buddy-demo`。
