# T05 · V2 前端：定目标 5 问 + 大纲卡

> 执行：Grok（Cursor）· 分支 `grok/t05-v2-goal-ui` · 依赖：T03 和 PR #9（联调修复，对话里的 `<PlanLine inChat>`）已合并 · 先读 README、`docs/v2/V2-方案.md` 5.1 / 11.2，并打开原型 `docs/v2/prototype/index.html` 看交互

## 目标
V2 打开时，新用户在对话里按 V2 的 5 道题定目标，看到学习大纲卡，可以改，点“好”后今天三件出现。

## 要做的
1. `web/src/lines/v2/api.ts`：`getStatus()`（`GET /api/v2/status`，404 或连不上 = 关闭）、`draftOutline`、`patchOutline`、`acceptOutline`、`undoOutline`（接口见 T03）。用 `web/src/api/client.ts` 的 `api()`。
2. `web/src/lines/v2/GoalFlowV2.tsx`：一次只问一题，共 5 题（`docs/v2/V2-方案.md` 5.1）。每题有快捷回复按钮 + 输入框 + “先跳过”。跳过的题不算用户的选择（规则 6），用默认值并在提交前的确认里写明“这些是先按默认排的”。第 4 题选“没有”或“有，晚点交”时走没资料的路；选“有，现在交”时提示“V2 先支持没资料这条路，资料可以之后再交”，仍按没资料走。
3. `web/src/lines/v2/OutlineCard.tsx`：显示大纲（单元 + 要点，可折叠），标 `label`（“AI 整理，可以改”或“模拟”）。按钮：“好”（主按钮）/“改一改”/“先不用”。
   - “改一改”：单元名、要点可以直接编辑，能删单元、加单元；保存调 `patchOutline`。
   - “好” → `acceptOutline` → 刷新页面（照计划线现在的做法）。点“好”后显示“已按这份大纲排好，今天的三件在左边”和“撤销”按钮（当天有效）。
   - 大纲卡上固定一行小字：“通用知识整理，没有资料出处；交了资料后可以排得更准”。
4. **挂载**（只改 `web/src/components/Shell.tsx` 这几处）：
   - 读一次 `getStatus()`，存 `v2Enabled`。
   - 对话流里现在是 `<PlanLine inChat showDemo={DEV} />`：当 `v2Enabled && plan.needs_setup` 时改为渲染 `<GoalFlowV2 />`；其余情况不变。
   - 问答回答或练习题的资料来自 `v2-outline-` 文件时（问答的 `references[].lecture_id` 对应的文件名以“AI 学习大纲”开头），在回答上加 `Badge`“通用知识，没有出处”（规则 9）。如果现有数据拿不到文件名，就按 `GET /api/qa/lectures` 的标题判断。
5. 测试 `web/src/lines/v2/*.test.ts`：5 问的前进 / 跳过 / 默认值逻辑；大纲编辑的校验（标题不能空、1–20 个单元）。

## 不能动
- 其他线的组件（`web/src/lines/{plan,qa,practice,materials,dashboard}/`）。
- `ui.tsx` 组件签名；`styles.css` 只能在文件末尾加 `/* V2 */` 段，只用现有变量。

- [ ] 改一个单元名、删一个单元后点“好”：左栏出现“学第 1 讲”等任务，单元数和大纲一致；撤销能回到定目标前。
