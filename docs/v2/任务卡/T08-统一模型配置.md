# T08 · 统一模型配置（等 A 定主备模型后开工）

> 执行：Grok（Cursor）· 分支 `grok/t08-model-config` · 依赖：**A 定好“快”“强”两档各用哪个主模型、哪个备模型** · 先读 README

## 背景
现在有 3 份模型配置，用的模型还不一样：
- 练习线 `app/study/practice/models.json`（deepseek-v4-pro 主 / qwen3.7-plus 备）
- 资料线 `config/materials-models.example.json`（deepseek-flash / deepseek-v4-pro）
- 部署 `deploy/xiaoman/models.example.json`（deepseek-flash / deepseek-v4-pro）

## 要做的
1. 只保留一份：`deploy/xiaoman/models.example.json` 的格式（`models` + `tiers: {fast:[主,备], strong:[主,备]}`），填 A 定的模型。密钥只写环境变量名（`api_key_env`），**不写任何真实密钥**。
2. 练习线、资料线改为读这一份（经底座网关 `app/gateway/` 的 tier，不再各自指定模型）。如果某条线需要特殊参数（例如关思考、JSON 输出），用网关支持的方式按能力名配置，在 PR 里列出每个能力最终用哪一档：
   - 快：`qa.intent`、`plan.opening`
   - 强：`qa.answer`、`materials.summary`、`practice.generate`、`practice.check`、`practice.rephrase`、`goal.outline`、`dashboard.eval`
3. 删掉另外两份配置文件；`README` 和 `.env.example` 里的说明同步改。
4. 不改任何提示词文件。

## 验收
- [ ] 仓库里只剩一份模型配置；`grep -r "deepseek\|qwen" app config` 只出现在这一份和文档里。
- [ ] 不设任何密钥时，全部能力走模拟，`pytest` 全绿。
- [ ] 设了 A 提供的测试密钥后（A 本机验证，不进 CI），每个能力各调一次成功，`llm_calls` 里记录的模型名与配置一致。
