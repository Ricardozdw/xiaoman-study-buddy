# T07 · V2 前端：阶段测验卡、成绩报告卡、完成卡

> 执行：Grok（Cursor）· 分支 `grok/t07-v2-cards` · 依赖：T04、T06 已合并（T05 已合并更好）· 先读 README、`docs/v2/V2-方案.md` 5.4 / 5.5，原型 `docs/v2/prototype/`

## 要做的（都在 `web/src/lines/v2/`）
1. `AssessmentCard.tsx`
   - 页面打开时调 `GET /api/v2/assessment/due`；`due=true` 时在对话流里出一张卡：“考考这一阶段？大约 15 分钟”，按钮“开始”（主按钮）/“晚点再考”。“晚点再考”只收起，当天不再出。
   - “开始” → `POST /api/v2/assessment/start` → 一张卡里依次做 10 题（一次一题，选项按钮要能换行，参考 T01 的 `.btn.option`），可以“上一题 / 下一题”，最后“交卷”。题目标 `label`；资料来自学习大纲时加 `Badge`“通用题，没有出处”。
   - 交卷 → `POST /api/v2/assessment/{id}/submit`。
2. `ReportCard.tsx`：显示总分、每单元“对 x / y”、薄弱单元（“第 3 单元再看一眼会更稳”）、`summary` 文案。不出现“不及格”“差”等词。按钮“好的”收起。
3. `CompletionCard.tsx`
   - 调 `GET /api/v2/completion`：`suggest=true` 时出建议卡“看起来可以收尾了”，按钮“完成目标”（主）/“再学一阵”。
   - 左栏或对话底部提供一个次要入口“我学完了”，点了出同一张确认卡（`reason: "user_said"`）。
   - 确认后显示完成卡：学了几天、做了几题、阶段测验从 x 分到 y 分、最难的单元；按钮“定下一个目标”/“先休息一阵”（前者暂时只提示“V2.0 先支持一个目标，下一个目标在 V2.3 做”）。当天可“撤销”。
4. **挂载**：只在 `web/src/components/Shell.tsx` 对话流里加 `{v2Enabled && <V2Cards />}` 一处（`V2Cards` 内部按顺序：完成建议 > 测验 > 报告，一次只出一张卡，规则 3）。
5. 测试：题目切换与交卷前未答题提示；报告文案不含禁用词（写一个禁用词列表测试）。

## 不能动
- 其他线组件；`ui.tsx` 签名；`styles.css` 只在末尾 `/* V2 */` 段追加。
