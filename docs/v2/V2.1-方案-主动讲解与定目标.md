# V2.1 方案 · 主动讲解 + 定目标入口

> 日期：2026-11-07 · 状态：需求已锁定，待开发

## 一、需求（锁定版）

### 1. 语义识别「目标 vs 闲聊」
- 不靠「我要学 / 我要转行」等固定词，模型**理解语义**判断用户是在表达一个学习目标，还是闲聊/提问。
- 命中「目标」且还没定目标 → 进入定目标；已定目标再说新目标 → 走改目标确认。

### 2. 完整学习闭环（不用用户先上传资料）
```
说目标（语义识别）→ 定目标（每天时间/完成时间）→ 生成学习大纲
→ 每天 3 个任务：
    ① 学新的（小满讲这一讲：讲解正文 + 例子，标注「通用知识，没有出处」）
    ② 练一练（针对今天学的巩固题）
    ③ 考试（固定最后一个，检验当天学习成果；考试里带上之前做错的题）
→ 学完 3 件可「继续学下一讲」（多学，不限制）
→ 全部学完 → 目标完成
```

## 二、实现拆分（按顺序）

### 块 1：通用讲解能力 `unit.lecture`（核心）
- 新增提示词 `app/prompts/unit.lecture/v1.md`：输入目标背景 + 单元标题 + 要点 + 已学内容摘要，输出分小节讲解（每节 heading + 正文 + 例子）。
- 强档模型（deepseek-reasoner）。输出结构校验。
- 后端新增 `app/study/v2/lecture.py`：生成/读取讲解；讲解落到讲次对应的资料页，问答/出题可引用。
- 端点：`POST /api/v2/units/{no}/lecture`（首次生成，之后读取缓存）。
- 生成时机：确认大纲时自动生成第 1 讲；其余按需生成（点「学第 N 讲」时）。
- 前端：点「学第 N 讲」→ 对话里出现讲解卡（分节 + 例子）→ 快捷回复「出几道题 / 有疑问 / 下一讲」。

**验收**：定目标 → 确认大纲 → 点「学第一讲」→ 看到真实讲解（非标题+要点）→ 可出题/提问 → 点完成进入下一件。

### 块 2：定目标意图（语义）
- `qa.intent` 加第 5 类 `goal`，提示词改为语义判断（示例覆盖各种说法，不依赖固定词）。
- 命中 `goal` 且 needs_setup → 从原句抽取目标名/类型，接「每天时间 → 完成时间」快捷回复 → 生成大纲。
- 已定目标再说新目标 → 改目标确认卡。

**验收**：新用户说「我想学 AI 产品经理」→ 直接进定目标（不再闲聊）；说「今天好累」→ 仍走闲聊。

### 块 3：每天三件重构（考试固定为第 3 件）
- 计划线排程改为：① 学新的 ② 练一练 ③ 考试（固定最后）。
- 考试题 = 当天所学讲次的题目 + 之前做错的题（补一补并入考试）。
- 学完 3 件后可继续「学下一讲」，不限制每日件数上限（多学）。

**验收**：每天三件固定「学、练、考」；考试含错题；学完可继续下一讲。

### 块 4：大纲保留 + 下一步引导
- 确认大纲后大纲保留在左栏/工作台可随时查看。
- 确认后明确引导：「大纲好了，我们从第一讲：xxx 开始」+ 快捷入口。

**验收**：确认大纲后左栏能看到大纲，对话明确下一步。

## 三、顺序与依赖
- 块 1（通用讲解）先行，是产品立住的核心，且块 3 的「学新的」依赖它。
- 块 2 与块 1 并行可做（改分类器 + 目标流程）。
- 块 3、块 4 依赖块 1 完成。
